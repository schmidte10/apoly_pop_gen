# Outlier analysis

## PCAdapt

``` r
apoly_populations_kplot <- pcadapt(input = apoly_pcadapt, K=10)
pdf("outputs/apoly_populations_kplot.pdf")
plot(apoly_populations_kplot, option = "screeplot")
dev.off() 
```

A K value of 2 is most approproate, as this is the value of K after
which the curve starts to flatten out more. This means we have
identified the PC’s that capture population structure.

``` r
apoly_populations_pca <- pcadapt(input =apoly_pcadapt, K =3)
write.table(apoly_populations_pca$scores, "outputs/pcadapt_scores.txt")
summary(apoly_populations_pca)
```

## significant outliers

``` r
apoly_populations_padj <- p.adjust(apoly_populations_pca$pvalues, method ="bonferroni") 
alpha <- 0.1 #[adjust as necessary]
outliers <- which(apoly_populations_padj < alpha) 
length(outliers) 

write.table(outliers, file="outputs/apoly_populations_pcaoutliers.txt") 
```

## BAYPASS

### load software

``` bash
module load plink
```

For this analysis use the metadata file that lists populations in the
first column and individuals in the second column.

First we will create a .ped file

``` bash
plink --vcf data/gatk.filtered.relaxed_studywide.bicolor.biallelic.vcf.gz --recode --allow-extra-chr --out baypass/gatk.filtered.relaxed_studywide.bicolor.biallelic.plink
```

Remove first two columns

``` bash
cut -d' ' -f3- baypass/gatk.filtered.relaxed_studywide.bicolor.biallelic.plink.ped > baypass/x.delete
```

``` bash
paste -d' ' data/apoly_populations_metadata_POPIND.txt baypass/x.delete > baypass/gatk.filtered.relaxed_studywide.bicolor.biallelic.plink.ped
```

``` bash
plink --file baypass/gatk.filtered.relaxed_studywide.bicolor.biallelic.plink --allow-extra-chr --freq counts --family --out baypass/apoly_populations
```

``` bash
npop2=12 #the number of populations you have times 2 
tail -n +2 baypass/apoly_populations.frq.strat | awk '{ $9 = $8 - $7 } 1' | awk '{print $7,$9}' | tr " " "\n" | awk -v pp=${npop2} '{if (NR % pp == 0){a=a $0"";print a; a=""} else a=a $0" "}' > baypass/apoly_populations_baypass.txt 
```

## run BAYPASS

``` bash
g_baypass singularity run /fast/tmp/containers/baypass_public-v2.41.sif g_baypass -npop 6 -gfile baypass/apoly_populations_baypass.txt -outprefix apoly_populations_baypass -nthreads 4
```
